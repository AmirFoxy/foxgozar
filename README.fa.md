# فاکس‌گذر (FoxGozar)

فاکس‌گذر روی روترِ OpenWrt شما نصب می‌شود و اینترنتِ همه‌ی دستگاه‌های خانه (گوشی، لپ‌تاپ، تلویزیون، کنسول بازی) را از سرورهای VPN شما عبور می‌دهد. روی خودِ دستگاه‌ها هیچ برنامه‌ای لازم نیست: هر چیزی که به وای‌فای یا کابلِ روتر وصل باشد، پوشش داده می‌شود.

مدیریتش از صفحه‌ی وبِ خودِ روتر (LuCI) انجام می‌شود، به فارسی یا انگلیسی، با تمِ روشن یا تیره.

## چه کارهایی می‌کند

- **اتصال شما را قطع نمی‌کند** وقتی سرور اضافه، حذف یا عوض می‌کنید
- **سریع‌ترین سرور را خودش انتخاب می‌کند** و وقتی یکی کند یا قطع شد، عوضش می‌کند
- **پشتیبانِ رایگانِ WARP** که وقتی همه‌ی سرورها قطع‌اند، جایگزین می‌شود
- **کنترلِ جداگانه‌ی هر دستگاه:** از تونل، مستقیم، از یک سرورِ مشخص، یا بدون اینترنت
- **ساعت‌های بدون اینترنت برای هر دستگاه**، هر روز (مثلاً ۲۳ تا ۷ صبح)، حتی وقتی تونل خاموش است
- **سایت‌های ایرانی مستقیم** (سریع‌تر، و از حجمِ سرورتان کم نمی‌کند)
- **قوانینِ خودتان:** دامنه، رنجِ IP، `keyword:` یا لینکِ یک لیست که هر روز به‌روز می‌شود
- **سریع‌ترینِ یک اشتراک:** انتخابِ خودکار فقط بینِ سرورهای یک اشتراک
- **هشدار** چند روز قبل از تمام شدنِ تاریخ یا حجمِ اشتراک
- **پشتیبان‌گیری و بازگردانی** همه‌چیز در یک فایل؛ تنظیمات با ارتقای firmware هم پاک نمی‌شوند
- **اشتراکِ اینترنتِ روتر** با دیگران از طریقِ اینترنتِ داخلی (برای قطعی، وقتی روتر استارلینک دارد)، و حالتِ `dualwan` که پورتِ دوم را اینترنتِ داخلی می‌کند
- **مسدودسازیِ تبلیغات، بدافزار و فیشینگ** برای همه‌ی دستگاه‌ها
- **کیل‌سوییچ:** اگر تونل قطع شود، دستگاه‌ها آفلاین می‌مانند، نه بدون محافظت
- **پینگِ واقعیِ بازی‌ها** تا سرورهای Dota 2، CS2، League of Legends، Valorant و بقیه
- **QR کد** برای استفاده از همان سرورها روی گوشی، بیرون از خانه
- پشتیبانی از لینک‌های کانفیگ (vless، vmess، trojan، ss، hy2، tuic و …)، اشتراک‌ها، کانفیگِ Clash / Clash Meta و کانفیگ‌های JSONِ Xray و sing-box

## آموزشِ نصب، قدم به قدم و از صفر

لازم نیست لینوکس بلد باشید. قدم‌ها را به ترتیب انجام دهید؛ هر قدم دقیقاً می‌گوید چه چیزی تایپ کنید.

### چه چیزهایی لازم است

- روتری با **OpenWrt نسخه‌ی 22.03 یا جدیدتر**. (OpenWrt سیستم‌عاملِ روتر است. اگر روترتان هنوز نرم‌افزارِ کارخانه را دارد، اول OpenWrt نصب کنید: مدلِ روترتان را در <https://firmware-selector.openwrt.org> پیدا کنید.)
- حدود **۱۳۰ مگابایت فضای خالی** روی روتر و **۲۵۶ مگابایت رم** یا بیشتر
- روتر به اینترنت وصل باشد
- یک کامپیوترِ ویندوز، مک یا لینوکس که به شبکه‌ی روتر وصل است
- دست‌کم یک سرورِ VPN: لینکِ کانفیگ (که با `vless://`، `vmess://`، `trojan://` و … شروع می‌شود) یا لینکِ اشتراک از فروشنده‌تان

### قدم ۱: باز کردنِ ترمینال روی کامپیوتر

- **ویندوز ۱۰ / ۱۱:** دکمه‌ی Start را بزنید، `PowerShell` را تایپ کنید و بازش کنید.
- **مک:** Launchpad را باز کنید، `Terminal` را تایپ کنید و بازش کنید.
- **لینوکس:** برنامه‌ی Terminal را باز کنید.

پنجره‌ای باز می‌شود که در آن دستورها را تایپ می‌کنید و بعد از هر کدام **Enter** می‌زنید.

### قدم ۲: وصل شدن به روتر

تایپ کنید:

```sh
ssh root@192.168.1.1
```

- اگر آدرسِ روترتان فرق دارد، به‌جای `192.168.1.1` همان را بنویسید.
- بارِ اول می‌پرسد `Are you sure you want to continue connecting?`؛ بنویسید `yes` و Enter بزنید.
- بعد رمز را می‌خواهد: همان رمزی را بنویسید که با آن وارد صفحه‌ی وبِ روتر می‌شوید. موقعِ تایپ چیزی نمایش داده نمی‌شود؛ این طبیعی است. Enter بزنید.

وقتی خطی دیدید که به `root@OpenWrt:~#` ختم می‌شود، داخلِ روتر هستید.

### قدم ۳: پیدا کردنِ نسخه و معماریِ روتر

همچنان داخلِ روتر، تایپ کنید:

```sh
cat /etc/openwrt_release
```

دنبالِ دو خط بگردید، مثلاً:

```
DISTRIB_RELEASE='25.12.6'
DISTRIB_ARCH='arm_cortex-a7_neon-vfpv4'
```

هر دو را یادداشت کنید:

- **نسخه** (`DISTRIB_RELEASE`): اگر **۲۵ یا جدیدتر** است، فایلِ **`.apk`** لازم دارید. اگر **۲۴ یا قدیمی‌تر** است، فایلِ **`.ipk`**.
- **معماری** (`DISTRIB_ARCH`): اسمِ دقیقش، مثلاً `arm_cortex-a7_neon-vfpv4`، `aarch64_cortex-a53` یا `mipsel_24kc`.

### قدم ۴: دانلودِ پکیج

1. صفحه‌ی [Releases](../../releases) را باز کنید و جدیدترین نسخه را باز کنید.
2. در بخشِ **Assets** فایلی را پیدا کنید که اسمش با **معماریِ شما** و **نوعِ فایلِ شما** تمام می‌شود. مثلاً برای روترِ بالا:
   `foxgozar_6.13.3-r1_arm_cortex-a7_neon-vfpv4.apk`
3. دانلودش کنید. در پوشه‌ی **Downloads** ذخیره می‌شود.

معماری باید دقیقاً یکی باشد: `arm_cortex-a7` و `arm_cortex-a7_neon-vfpv4` دو فایلِ متفاوت‌اند.

### قدم ۵: کپی کردنِ پکیج روی روتر

یک پنجره‌ی ترمینالِ **دوم** باز کنید (پنجره‌ی اول را که به روتر وصل است، باز بگذارید) و این دو دستور را بزنید. اسمِ فایل را با اسمِ فایلی که دانلود کردید عوض کنید:

```sh
cd Downloads
scp -O foxgozar_6.13.3-r1_arm_cortex-a7_neon-vfpv4.apk root@192.168.1.1:/tmp/
```

دوباره رمزِ روتر را می‌خواهد. وقتی نوارِ پیشرفت به ۱۰۰٪ رسید، فایل روی روتر است.

> ترجیح می‌دهید فایل را با کشیدن و رها کردن منتقل کنید؟ برنامه‌ی [WinSCP](https://winscp.net) هم کار می‌کند: پروتکلِ **SCP** را انتخاب کنید، با کاربرِ `root` وارد شوید و فایل را در پوشه‌ی `/tmp` بیندازید.

### قدم ۶: نصب

به پنجره‌ی ترمینالِ **اول** برگردید (همان که داخلِ روتر است).

**OpenWrt نسخه‌ی ۲۵ یا جدیدتر (`.apk`):**

```sh
apk update
apk add --allow-untrusted /tmp/foxgozar_*.apk
```

**OpenWrt نسخه‌ی ۲۴ یا قدیمی‌تر (`.ipk`):**

```sh
opkg update
opkg install /tmp/foxgozar_*.ipk
```

دستورِ اول فهرستِ پکیج‌های روتر را به‌روز می‌کند و دستورِ دوم فاکس‌گذر و دو بخشِ کوچکِ سیستمی که لازم دارد را نصب می‌کند. `--allow-untrusted` لازم است چون این پکیج از فروشگاهِ خودِ OpenWrt نیست.

### قدم ۷: باز کردنِ فاکس‌گذر

1. در مرورگر به `http://192.168.1.1` بروید و وارد شوید.
2. از منوی بالا **Services ← FoxGozar** را باز کنید (اگر زبانِ LuCI فارسی است: **سرویس‌ها ← FoxGozar**).

اگر آن را نمی‌بینید، یک بار خارج و دوباره وارد شوید، یا `Ctrl + F5` بزنید تا صفحه دوباره بارگذاری شود.

### قدم ۸: افزودنِ سرورها

**با لینکِ کانفیگ:** زبانه‌ی **سرورها** ← **افزودن سرور** ← یک یا چند لینک را بچسبانید (هر کدام در یک خط) ← **افزودن سرور**.

**با اشتراک:** زبانه‌ی **اشتراک‌ها** ← **افزودن اشتراک** ← لینکِ اشتراک را بچسبانید ← **افزودن اشتراک**. اشتراک، سرورهایش را خودش به‌روز نگه می‌دارد.

### قدم ۹: اتصال

دکمه‌ی گردِ بزرگِ بالای صفحه را بزنید.

بارِ اول چند دقیقه **در حال آماده‌سازی…** نشان می‌دهد، چون روتر هسته‌ها (sing-box، و اگر سرورهایتان لازم داشته باشند Xray) را دانلود می‌کند؛ حدود ۱۰۰ مگابایت. از آن به بعد اتصال کمتر از یک ثانیه طول می‌کشد.

وقتی **وصل است** نمایش داده شد، همه‌ی دستگاه‌های روتر از تونل استفاده می‌کنند. می‌توانید پنجره‌های ترمینال را ببندید.

### قدم ۱۰: تنظیماتِ پیشنهادی

| کجا | تنظیم | چرا |
|---|---|---|
| مسیریابی | **سایت‌های ایرانی مستقیم** (پیش‌فرض روشن است) | سریع‌تر، و حجمِ سرور را مصرف نمی‌کند |
| مسیریابی | **مسدودسازی تبلیغات** | تبلیغ‌ها و ردیاب‌ها را روی همه‌ی دستگاه‌ها حذف می‌کند |
| مسیریابی | **مسدودسازی بدافزار و فیشینگ** | محافظت برای کلِ خانه |
| تنظیمات | **وقتی همه سرورها قطع شدند از WARP استفاده کن** | پشتیبانِ رایگان تا اینترنت قطع نشود |
| تنظیمات | **کیل‌سوییچ** | اگر تونل قطع شود، چیزی بدون محافظت بیرون نمی‌رود |

برای اینکه تعیین کنید هر دستگاه چطور وصل شود، زبانه‌ی **دستگاه‌ها** را باز کنید. دکمه‌ی ساعت کنارِ هر دستگاه، ساعت‌های بدون اینترنتِ آن را تنظیم می‌کند.

### برای قطعی اینترنت: استارلینک به‌علاوه‌ی اینترنتِ داخلی

اگر اینترنتِ بین‌الملل قطع باشد ولی شبکه‌ی داخلی کار کند و استارلینک (یا راهِ دیگری به بیرون) داشته باشید، روتر می‌تواند هر دو را بگیرد و استارلینک را با کسانی در جاهای دیگرِ ایران شریک شود:

1. در SSH بزنید `foxgozar dualwan on --yes`. پورتِ LANِ روتر پورتِ اینترنتِ دوم (wan2) می‌شود. استارلینک را به پورتِ WAN و اینترنتِ داخلی را به پورتِ دیگر وصل کنید. از این به بعد با وای‌فای به روتر وصل شوید. آدرس‌های ایرانی از اینترنتِ داخلی می‌روند و بقیه از استارلینک.
2. در زبانه‌ی **اشتراک‌گذاری**، سرورِ اشتراک‌گذاری را روشن کنید. اگر مودمِ داخلی خودش روتر است، پورت (پیش‌فرض ۸۴۴۳) را روی آن به این روتر فوروارد کنید.
3. برای هر نفر یک بار **حساب جدید** را بزنید و اسمش را بنویسید (اگر خواستید سقفِ حجم هم بگذارید). لینک و QR همان لحظه نشان داده می‌شود: QR را حضوری نشان دهید یا لینک را با پیامک بفرستید (پیام‌رسان‌های داخلی زیر نظرند). **کپی پیام** لینک را همراه با یک راهنمای کوتاه کپی می‌کند. هر کس باید v2rayNG، Hiddify یا Streisand را از قبل نصب کرده باشد، چون در قطعی فروشگاه‌های برنامه کار نمی‌کنند.
4. این زبانه نشان می‌دهد چه کسی وصل است و هر نفر چقدر مصرف کرده. هر حساب را می‌توانید با کلیدش متوقف کنید، لینکش را عوض کنید یا حذفش کنید، بدون اینکه بقیه اثر بگیرند. حسابی که سقف حجم دارد، وقتی به آن برسد خودش متوقف می‌شود.

`foxgozar dualwan off --yes` پورت را دوباره LAN می‌کند.

## به‌روزرسانی

پکیجِ جدید را دانلود کنید و **قدم‌های ۵ و ۶** را تکرار کنید. سرورها و تنظیماتتان حفظ می‌شوند.

## حذف

داخلِ روتر (قدم ۲):

```sh
apk del foxgozar          # OpenWrt 25 or newer
opkg remove foxgozar      # OpenWrt 24 or older
rm -rf /etc/foxgozar /usr/share/foxgozar
```

خطِ آخر سرورهای ذخیره‌شده و هسته‌های دانلودشده را هم پاک می‌کند.

## مشکلاتِ رایج

**`ssh` پیامِ «Connection refused» می‌دهد یا جواب نمی‌دهد.** مطمئن شوید کامپیوتر به وای‌فای یا کابلِ همین روتر وصل است و آدرس درست است (آدرس روی برچسبِ روتر نوشته شده، یا در جزئیاتِ شبکه‌ی کامپیوتر به اسمِ *gateway* آمده).

**`scp` با خطای «subsystem request failed» یا «sftp» متوقف می‌شود.** `-O` را دقیقاً مثلِ قدم ۵ اضافه کنید.

**نصب می‌گوید معماری جور نیست.** فایلِ معماریِ دیگری را دانلود کرده‌اید. قدم‌های ۳ و ۴ را تکرار کنید.

**نصب نمی‌تواند `kmod-nft-tproxy` یا `ca-bundle` را دانلود کند.** روتر اینترنت ندارد، یا `apk update` / `opkg update` اجرا نشده. اینترنت را درست کنید و قدم ۶ را دوباره انجام دهید.

**روی «در حال آماده‌سازی…» می‌ماند یا «اتصال برقرار نشد» نشان می‌دهد.** روتر نتوانسته هسته‌ها را از GitHub دانلود کند. **تنظیمات ← پیشرفته** را باز کنید، آدرسِ یک میرورِ GitHub را در **میرور GitHub** بگذارید و دوباره دکمه‌ی اتصال را بزنید. زبانه‌ی **گزارش** دلیلِ دقیق را نشان می‌دهد.

**وصل است ولی سایت‌ها باز نمی‌شوند.** زبانه‌ی **سرورها** را باز کنید و **تست همه** را بزنید. سرورهای خراب را با **حذف خراب‌ها** پاک کنید یا سرورِ تازه اضافه کنید.

**«سرویس فاکس‌گذر جواب نمی‌دهد».** در حالِ شروع است؛ چند ثانیه صبر کنید. اگر ماند، داخلِ روتر دوباره راه‌اندازی‌اش کنید: `/etc/init.d/foxgozar restart`

## ساختن از روی سورس

به [Go](https://go.dev) نیاز دارد (نسخه‌اش در `go.mod` است)؛ OpenWrt SDK لازم نیست.

```sh
go test ./...
go run ./tools/mkpkg -version 6.14.0 -out dist -arch arm_cortex-a7_neon-vfpv4   # one architecture
go run ./tools/mkpkg -version 6.14.0 -out dist                                  # all of them
```
